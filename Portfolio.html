Coding Challenge 5:

Yay I learned how to use an API! This is the API I used: https://api.worldbank.org/v2/country/ZA/indicator/EG.ELC.ACCS.ZS?format=json&date=1990:2024. The base URL is https://api.worldbank.org/v2/ and the elements needed include the country (ZA), the indicator (EG.ELC.ACCS.ZS), the format (json) and the date range (1990:2024). The data is returned in JSON format, and it is in a clean (tidy) format. The full final URL that I used in my chart is: https://api.worldbank.org/v2/country/ZA/indicator/EG.ELC.ACCS.ZS?format=json&date=1990:2024
